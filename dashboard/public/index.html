                      @QA Studio Bot run <suite> <dev|qc|prod>
                      Chạy Test Suite (Ví dụ: @QA Studio Bot run smoke dev)
                    
      
                    
      
                      @QA Studio Bot run file <đường_dẫn_file> <env>

                      @QA Studio Bot run check dev
                      Kiểm tra tính toàn vẹn của framework (Lint & Config verification)
                    
      
                    
      
                      @QA Studio Bot help
                      Xem danh sách toàn bộ các Test Suites đang có sẵn

       Bước 1: Tạo Bot trên Discord
      
                          
      Tạo bot để tester chỉ cần chat là bot tự động chạy test.
      
                        
      
                        
                           Discord Portal
                        
                      
      
                      
      
                        
      
                          1.1
                          
      
                            Tạo hồ sơ Bot mới:
                            
      Mở Discord Developer Portal -> Bấm nút màu tím "New Application".
      
                            
      Ở ô NAME, gõ: QA Studio Bot -> Tích ô đồng ý -> Bấm Create.
      
                          
      
                        
      
                        
      
                          1.2
                          
      
                            Lấy mã chìa khóa Token của Bot:
                            
      Chọn menu "Bot" bên trái -> Tìm mục TOKEN -> Bấm "Reset Token" -> Bấm "Yes, do it!".
      
                            
      Bấm nút "Copy" để sao chép token.
      
                            
      👉 Dán vào: Ô DISCORD BOT TOKEN ở bảng bên trái.
      
                            
                            
      
                              
                              
      
                                Bắt buộc: Cuộn xuống tìm Privileged Gateway Intents -> Bật MESSAGE CONTENT INTENT (ON) -> Bấm Save Changes.
                              
      
                            
      
                          
      
                        
      
                        
      
                          1.3
                          
      
                            Mời Bot vào Server Discord:
                            
      Chọn "OAuth2" -> "URL Generator" -> Tích chọn [x] bot.
      
                            
      Tại BOT PERMISSIONS, tích chọn 4 quyền:
      
                            
        
                              
      •  Send Messages
        • 
                              
      •  Read Messages/View Channels
        • 
                              
      •  Read Message History
        • 
                              
      •  Embed Links
        • 
                            
      
                            
      Bấm Copy URL ở đáy trang -> Mở tab trình duyệt mới -> Mời bot vào server.
      
                            
      ✅ Thấy QA Studio Bot trong danh sách server là thành công!
      
                          
      
                        
      
                      
      
                      
      
                        
                      
      
                    
      

                    
                    
      
                      
      
                        
      
                          
       Bước 2: Lấy Channel ID & Webhook URL
      
                          
      Chỉ định kênh nhận lệnh và bắn kết quả báo cáo.
      
                        
      
                      
      
                      
      
                        
      
                          2.1
                          
      
                            Bật Developer Mode:
                            
      Cài đặt User Settings (Bánh răng) -> Nâng cao (Advanced) -> Bật Chế độ nhà phát triển (Developer Mode).
      
                          
      
                        
      
                        
      
                          2.2
                          
      
                            Lấy Allowed Channel ID:
                            
      Chuột phải vào kênh muốn nhận lệnh (vd: #qa-automation) -> Chọn Sao chép ID kênh (Copy Channel ID).
      
                            
      👉 Dán vào: Ô ALLOWED CHANNEL ID ở bảng bên trái.
      
                          
      
                        
      
                        
      
                          2.3
                          
      
                            Lấy Webhook URL:
                            
      Chuột phải vào kênh -> Chỉnh sửa kênh (Edit Channel) -> Tích hợp (Integrations) -> Webhooks -> Tạo mới -> Sao chép URL Webhook.
      
                            
      👉 Dán vào: Ô DISCORD WEBHOOK URL ở bảng bên trái.
      
                          
      
                        
      
                      
      
                      
      
                        
                        
                      
      
                    
      

                    
                    
      
                      
      
                        
      
                          
       Bước 3: Tạo GitHub Token (Workflow Dispatch)
      
                          
      Cấp quyền cho Bot kích hoạt GitHub Actions chạy test.
      
                        
      
                        
                           GitHub Tokens
                        
                      
      
                      
      
                        
      
                          3.1
                          
      
                            Tạo Token mới:
                            
      Bấm Generate new token (classic) -> Đặt Note: Discord Bot Token -> Expiration: No expiration.
      
                          
      
                        
      
                        
      
                          3.2
                          
      
                            Tích chọn 2 quyền bắt buộc:
                            
        
                              
      •  repo (Toàn bộ quyền repo)
        • 
                              
      •  workflow (Kích hoạt GitHub Actions)
        • 
                            
      
                            
      Bấm Generate token -> Sao chép mã ghp_....
      
                            
      👉 Dán vào: Ô GITHUB PERSONAL TOKEN ở bảng bên trái.
      
                          
      
                        
      
                      
      
                      
      
                        
                        
                      
      
                    
      

                    
                    
      
                      
      
                        
      
                          
       Bước 4: Thêm Secret vào GitHub Repository
      
                          
      Cho GitHub Actions biết Webhook URL để bắn báo cáo về Discord.
      
                        
      
                        
                           GitHub Secrets
                        
                      
      
                      
      
                        
      
                          4.1
                          
      
                            Tạo Secret mới trên GitHub:
                            
      Bấm "New repository secret" -> Điền 2 trường:
      
                            
      
                              
      Name: DISCORD_WEBHOOK_URL
      
                              
      Secret: Dán lại Discord Webhook URL ở Bước 2.3
      
                            
      
                            
      Bấm Add secret để hoàn tất.
      
                          
      
                        
      
                      
      
                      
      
                        
                        
                      
      
                    
      

                    
                    
      
                      
      
                        
      
                          
       Bước 5: Bật Bot & Bắt Đầu Thưởng Thức!

                          5.1
                          
      
                            Lưu cấu hình:
                            
      Bấm nút màu tím "💾 Lưu cấu hình" ở góc trên bên phải Dashboard.
      
                          
      
                        
      
                        
      
                          5.2
                          
      
                            Bật Bot chạy ngầm:
                            
      Mở Terminal/PowerShell và chạy lệnh:
      
                            
      cd D:\_Automation-Project\discord-qa-bot && node bot.js
      
                            
      ✅ Khi hiện Ready: QA Studio Bot là bot đã thức dậy!
      
                          
      
                        
      
                        
      
                          5.3
                          
      
                            Thử ra lệnh trên Discord:
                            
      Gõ vào kênh chat Discord:
      
                            
      
                              @QA Studio Bot run smoke dev
                            
      
                            
      🎉 Bot sẽ lập tức kích hoạt test trên GitHub và tự động trả kết quả báo cáo về kênh chat!
